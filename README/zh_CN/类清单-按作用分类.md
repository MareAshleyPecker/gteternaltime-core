# GTET 类清单（按作用分类）

按**功能职责**归组，不按包路径。共 214 个类文件（Kotlin 201 + Java 13）。

> 包结构参考 GTO / GTCEu 家族惯例：`api / client / common / data / integration / mixin`，`common` 下按领域细分（`machine.multiblock.part.ae`、`data.material`…），语言键集中在 `data/lang`。
> 包名一律小写；例外：`mixin.GTM*` 按用户要求保持不动（与 `gtetcore.mixins.json` 的类名耦合）。
