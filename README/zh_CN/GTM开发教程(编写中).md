# GTM 开发教程（编写中）

> 这套教程面向**要往 GTET 里加机器的人**：从「一台机器怎么跑起来」（01）讲到模块化多方块怎么写（02 ~ 04），
> 最后是可直接抄写的 API 速查表与排错对照表（05），以及写给玩家 / 整合包作者的附录（06）。
> **读法**：想先懂原理就按 01 → 06 顺序读；只想解决眼前的问题可以直接跳读（查 API 看 05、做模块化看 02/03、动手写代码看 04）。
> 本教程已按主题拆分，每章顶部/底部都有上一节、下一节、返回目录的链接；所有 API 与行号都按 GTM 7.5.3 与本仓库源码核对过。
