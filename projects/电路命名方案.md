## 0. 三条不变的规矩

换方案时，换的只是"轴的选法"，以下三条任何方案都不能破：

1. **跨档恒定** —— 同一段位在每个电压档都用同一个词。
   （Star Technology 的规律性就来自这一条：后缀永远不变，只换主题词）
2. **单调递进** —— ① < ② < ③ < 最终，读起来必须"越来越强"。
3. **不撞车** —— 不能与本表已有的「主题词」和「最终后缀」重复，见 §3。

**阶梯长度规则**：越高档越短，缺的从**前面**砍。

| 电压 | 小电路个数 | 说明 |
|---|---|---|
| ZPM | 0 | 原版不动 |
| UV / UHV / UEV / UIV / UXV / OPV | 3 | ① ② ③ 齐全 |
| MAX | 2 | 缺 ① |
| ETV | 1 | 缺 ① ② |

### 3.2 中缀通用词决策矩阵

各档最终电路的中缀**现在是混用的**：演算 ×5 / 运算 ×2 / 解算 ×1。

| 序号 | 最终电路 | 现用中缀 |
|---|---|---|
| 1 | 自我意识**演算**核心 | 演算 |
| 2 | 灵魂量子**演算**主机 | 演算 |
| 3 | 维度拓扑**运算**架构 | 运算 |
| 4 | 因果律**演算**枢纽 | 演算 |

候选通用词逐个对着**每一档的最终电路**验证（✓✓ 强命中 / ✓ 成立 / ~ 偏弱 / ✗ 不通）：

| 主题（最终电路） | **演算** | 运算 | 解算 | 推演 |
|---|---|---|---|---|
| 自我意识演算核心 | ✓✓ | ~ | ✗ | ✓ |
| 灵魂量子演算主机 | ✓✓ | ~ | ✗ | ✓ |
| 维度拓扑运算架构 | ~ | ✓✓ | ✗ | ✗ |
| 因果律演算枢纽 | ✓ | ~ | ~ | ✓✓ |
| 悖论无限解算引擎 | ~ | ✗ | ✓✓ | ✓ |
| 超穷演算奇点 | ✓✓ | ✓ | ~ | ~ |
| 万有演算终枢 | ✓✓ | ✓ | ~ | ~ |
| 永恒时空运算矩阵 | ✓ | ✓✓ | ~ | ~ |
| **强命中数** | **5** | **3** | **1** | **2** |
| **完全不通数** | **0** | 1 | 4 | 1 |

**结论：通用词选「演算」。** 三条理由都能从上表核出来：

1. **它是现状主词** —— 8 档里 5 档已经在用，选它等于改动最小
2. **零"完全不通"** —— 唯一一个在全部 8 个主题上都不出错的候选
   （运算在"悖论无限"上不通；解算在 4 个主题上不通；推演在"维度拓扑"上不通）
3. **越往后越稳** —— 后段三档（超穷 / 万有 / 永恒时空）「演算」全部成立

**但保留两处语义例外**（有理由，不是偷懒）：

| 档 | 保留 | 理由 |
|---|---|---|
| 维度拓扑**运算**架构 | 运算 | "拓扑**运算**"是数学固定搭配（topological operation），换成"演算"反而不专业 |
| 悖论无限**解算**引擎 | 解算 | "**解算**"含"求解"义 —— 解悖论＝解方程，比"演算"精准得多 |

**应用规则**：小电路**跟本档最终电路用同一个中缀**，不要跨档强行统一。
即 UEV 的小电路用「运算」、UXV 的小电路用「解算」、其余用「演算」——
这样**每档内部读起来是齐的**，跨档的中缀差异则被两处语义例外解释了。

## 4. 推荐排序

1. **方案 T2（类空 / 类光 / 类时）** —— 纯「时间+空间」、递进严格嵌套、2 字词风格统一、
   且是时间空间专辑里**唯一不与 ETV「永恒时空」撞词**的方案；③ 类时 与「因果律」契合度最高
2. **方案 2（局域 / 全域 / 超距）** —— 物理味最正、零撞车、抽象名词与最终后缀语法统一
3. **方案 T1（长度收缩 / 时间膨胀 / 时空弯曲）** —— 最好懂、叙事最完整（空间→时间→统一），
   但 ③ 与 ETV 的"时空"字面重复，需接受这点小瑕疵
4. **方案 4（度规 / 联络 / 曲率）** —— 递进最严谨、专业感最强，适合硬核向玩家
5. **方案 1（观测 / 解析 / 操控）** —— 最稳、最好懂，保底方案
6. **方案 8（GT 原生四段）** —— 若能接受"放弃独特最终后缀"，规律性比上面全部方案都强

**混搭建议**（三选一）：

| 取向 | 组合 | 效果 |
|---|---|---|
| 物理向 | 方案 T2 | 类空 → 类光 → 类时 |

| 叙事向 | 方案 T1 | 长度收缩 → 时间膨胀 → 时空弯曲 |

**中缀通用词一律按 §3.2 的结论**：主词「演算」，仅 UEV 保留「运算」、UXV 保留「解算」。
